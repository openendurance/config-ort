# Scripts

This directory holds repository-level support files that are not part of the runtime application code.

## Contents

- `copilot-agent-mcp-config.json` - backup copy of the MCP server configuration used in the GitHub repository settings web UI. It preserves the approved tool endpoints and tool allow-lists so the configuration can be restored if the web UI settings are lost or need to be recreated.

## Notes

- Keep this file aligned with the GitHub repo settings configuration.
- Treat it as documentation and backup material, not as application runtime input.
