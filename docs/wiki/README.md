## Naming

Wiki pages are named `NN.PP-slug.md`:

- `NN` — two-digit zero-padded section number, starting at `01`; it sets the ordering of sections. Use the next unused number for a new section.
- `PP` — two-digit zero-padded page number within the section. `00` is the section index page; child pages start at `01` and increment. Use the next unused number within the section.
- `slug` — kebab-case title.

Do not reuse or renumber existing values.
