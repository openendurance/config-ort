## What Belongs Here

Artifacts produced by agent skill pipelines. These are outputs of automated analysis or transformation passes — they are not hand-authored and should not be hand-edited.

If you need to correct a finding in a generated document, re-run the originating skill with corrected inputs. Manual edits will be silently overwritten on the next run.

## Adding New Generated Subdirectories

When a new skill produces output:

- Create a subdirectory named after the skill
- Add it to the contents table above
- Add a README.md to the subdirectory identifying the originating skill, output format, and re-generation instructions

## Update Contract

Do not hand-edit. Re-run the originating skill to regenerate. If a skill's output format changes, update the subdirectory README accordingly.
